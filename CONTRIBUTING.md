# Contribuir

Obrigado por querer ajudar! / *Thanks for helping!*

1. Mudança grande ou app novo: comece uma conversa nas **[Discussions](https://github.com/cyfilho/ekfrase/discussions)**.
2. Leia o **[`AGENTS.md`](AGENTS.md)** (as regras em uma página) e, se precisar, o **[`docs/DESENVOLVER.md`](docs/DESENVOLVER.md)**.
3. Faça um fork e crie um ramo. Commits com **DCO** (`git commit -s`). Rode `npm run conferir`.
4. Abra um pull request contra o `main`, dizendo o que mudou e como conferir.

Erros: [Issues](https://github.com/cyfilho/ekfrase/issues).
